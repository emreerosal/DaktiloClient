# Public download-page text (publish with the Client repository)

DaktiloClient is a portable Windows x64 remote-support host. It displays a temporary connection code and a visible session/Stop control. The person given the code can access the screen, files and shared USB devices; keyboard/mouse control is enabled initially and can be switched off. There is no second connection approval dialog.

Launching prepares USB components and obtains a relay code. Missing USB components require Windows elevation and can install a separate persistent service and drivers. Closing the portable program does not uninstall those components. Review Privacy and System changes/uninstall before download.

Links to publish alongside the download: Client source repository, MIT license, Privacy policy, System changes/uninstall, Code signing policy, support contact and the exact release's SHA256.

Signing status: pending application; downloads are unsigned until an approved signing release is actually available. Do not describe them as Microsoft-verified or SignPath-signed yet. The provider's attribution is added only after acceptance.

No administrator software or administrator implementation is distributed on this page. The Client protocol is documented in its open source for interoperability.
